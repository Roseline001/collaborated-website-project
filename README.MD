## Project title and one-line description
Portfolio for Mitchelle Wakesho - a one-page portfolio for a budding full-stack Mitchelle Wakesho with links to testimonials, projects, and contact.

## Live demo link (GitHub Pages)
https://karumenick-dev.github.io/collaborated-website-project/

## Features list (bullet points)
* Responsive Layout: Designed to scale seamlessly across mobile devices, tablets, and desktop screens.

* Dynamic Testimonials Section: A clean, interactive showcase displaying reviews and endorsements from peers and collaborators.

* Direct Navigation Links: Quick-jump shortcuts routing users instantly to projects, background experience, and contact forms.

* Active State Styling: Enhanced UI interactive visual feedback that retains distinct button and navigation link colors once clicked.

## Technologies used
* HTML5: Structuring the core elements, semantic parts, and text content of the webpage.

* CSS3: Creating a custom responsive layout, configuring typography, and applying a cohesive warm color palette.

* JavaScript: Powering interactive features, DOM manipulation, handling click events, and managing dynamic lists.

## How to run it locally
1. Open the terminal and clone the repository:

   git clone https://github.com
   
2. Navigate into the project directory:
   
   cd collaborated-website-project
   
3. Open the project in VS Code:
   
   code .
   
4. Open the `index.html` file in your preferred web browser to view the application live.
